# Project Overview: Shellixa

## What is Shellixa?

**Shellixa** is a modern, open-source, **GUI-based SSH client** designed with a **Linux-first** philosophy. While currently optimized for the Linux ecosystem, Shellixa is built on a cross-platform foundation with plans to expand to Windows and macOS in the near future.

Inspired by premium commercial SSH clients, Shellixa aims to bridge the gap between basic terminal-based SSH and high-end proprietary tools, all while remaining fully open-source and community-driven.

## Why Shellixa Exits?

For a long time, Linux users have been caught between two worlds:
1.  **Terminal-only workflows**: Powerful but often cumbersome for managing hundreds of connections, keys, and session logs.
2.  **Proprietary GUI clients**: Feature-rich and beautiful, but often closed-source, expensive, or lacking deep Linux integration.

Shellixa exists to provide a **"Third Way"**: A professional-grade, open-source GUI that respects your privacy, fits perfectly into a Linux desktop environment, and enhances your productivity.

## Problems It Solves

-   **Connection Fragmentation**: No more searching through history or complex `~/.ssh/config` files. Shellixa provides specialized metadata (labels, tags) and inherited settings across groups.
-   **Key Management Headache**: Securely store and organize multiple SSH keys, certificates, and biometrics in a centralized Keychain.
-   **Session Chaos**: Organize multiple server sessions into **Workspaces**, enabling seamless switching between Split View and Focus Mode.
-   **Security Gaps**: Ensures that credentials and configurations are stored using an **End-to-End Encrypted (E2EE) Vault**.

## Key Highlights

-   **Multi-Protocol Power**: Native support for SSH, Mosh, Telnet, and SFTP.
-   **AI-Powered Productivity**: Integrated "Helium" autocomplete and "Gloria" AI agent for natural language shell commands.
-   **Real-time Collaboration**: "Multiplayer" mode for collaborative terminal sharing and troubleshooting.
-   **Advanced Tunneling**: Visual management of Port Forwarding (Local, Remote, Dynamic) and Jump Hosts.
