# Project Roadmap

The vision for Shellixa is to become the ultimate SSH workstation for Linux and beyond. Below are the planned milestones.

## 🗓️ Phase 1: Core Experience (Current)
- [x] Modern GUI Shell
- [x] Multi-Protocol (SSH, Mosh, SFTP)
- [x] E2EE Local Vault
- [x] Helium AI Autocomplete
- [x] Workspaces & Split View

## 🗓️ Phase 2: Power User Features (Upcoming)
- **Multiplayer Mode**: Real-time collaborative sessions.
- **Gloria AI Expansion**: Advanced shell scripting via natural language.
- **Visual Tunneling Manager**: Interactive map of all L/R/D port forwards.
- **Hardware Integrations**: FIDO2 and Biometric locks.

## 🗓️ Phase 3: Advanced Workflows
- **Team Collaboration**: Shared host lists for teams with E2E encryption.
- **Plugin System**: Allow community-built add-ons (like Kubernetes watchers, AWS integration).
- **Cloud Sync**: Optional, secure synchronization of settings across devices.
- **Mobile Companion**: View active session status and basic terminal on mobile (Roadmap).

## 🗓️ Phase 4: Full Cross-Platform Support
- **Windows Integration**: Native installer and deep integration with Windows Terminal and WSL.
- **macOS Optimization**: Metal-accelerated UI and native Keychain integration for Apple Silicon.
- **Global Distribution**: Official presence on the Mac App Store and Windows Store.
