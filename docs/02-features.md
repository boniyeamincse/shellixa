# Key Features

Shellixa is packed with features designed to make remote server management efficient, secure, and enjoyable.

### 🚀 Connectivity & Protocols
-   **Multi-Protocol Support**: Beyond standard SSH, natively support **Mosh** (for high-latency/mobile links), **Telnet**, and **SFTP**.
-   **Advanced Tunneling**: Robust support for Port Forwarding (Local, Remote, Dynamic), SOCKS/HTTP Proxies, and Jump Hosts (Bastion servers).
-   **Local Terminal**: Build-in local terminal emulator that can be integrated into project workspaces.

### 📂 Session Management
-   **Visual Host Management**: Organize servers into a logical hierarchy with a Drag-and-Drop interface.
-   **Inheritance**: Groups allow for inheritance of settings, credentials, and snippets across multiple hosts.
-   **Metadata**: Assign dedicated labels, tags, and colors to hosts for lightning-fast filtering.

### 📑 Workspaces & Productivity
-   **Project Workspaces**: Group multiple tabs by project or client. Switch instantly between **Split View** (dual panels) and **Focus Mode**.
-   **AI-Powered Autocomplete (Helium)**: Intelligent suggestions for commands, arguments, and file paths.
-   **AI Agent (Gloria)**: A natural language assistant that converts English requests into ready-to-run shell commands.
-   **Snippets**: Save frequently used command sequences and execute them globally with a single click.

### 🤝 Collaborative Multiplayer
-   **Real-time Sharing**: Share your terminal session with teammates for collaborative troubleshooting.
-   **No Server Software**: Works natively over SSH without requiring sidecar agents on the remote host.

### 🔒 Security & Syncing
-   **Encrypted Vault**: End-to-end encrypted storage for all hosts and credentials.
-   **Advanced Authentication**: Support for **FIDO2** hardware keys, **Biometric authentication**, and **SSH Certificates**.
-   **Cloud Syncing**: Seamlessly sync your workstation data across Linux, mobile, and other desktop platforms.

### 📊 Extra Utility Features
-   **Snippets & Scripts**: A dedicated panel for saving and running command sequences with one click.
-   **Connection Stats**: Real-time monitoring of active session resource usage and connection health.
-   **Smart Notifications**: Native desktop alerts for session events, server status changes, and critical errors.
