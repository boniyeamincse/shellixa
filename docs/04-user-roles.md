# User Roles

Shellixa is designed to cater to a variety of professional roles within the IT and security landscape. By understanding these roles, we tailor features to meet specific workflow needs.

## 🛠️ Developer
Developers use Shellixa for rapid prototyping, managing development servers, and interacting with containerized environments.
-   **Primary Needs**: Fast connection speeds, integrated key management, and terminal customization.
-   **Favorite Feature**: Quick Connect and split-pane terminal views.

## 🖥️ System Administrator
SysAdmins manage dozens or hundreds of servers across different data centers.
-   **Primary Needs**: Hierarchical host organization, connection groups, and robust logging for audit trails.
-   **Favorite Feature**: Connection Groups and Host Search.

## 🚀 DevOps Engineer
DevOps professionals bridge the gap between development and operations, often managing cloud-scale infrastructure.
-   **Primary Needs**: Automation integration, support for SSH tunnels, and port forwarding.
-   **Favorite Feature**: Advanced SSH Tunneling (Roadmap) and ProxyJump support.

## 🛡️ Security Analyst
Security professionals use Shellixa for forensic analysis, server auditing, and secure remote access.
-   **Primary Needs**: Absolute security of credentials, encrypted logs, and strict host verification.
-   **Favorite Feature**: Secure Credential Storage and Audit Logging.
