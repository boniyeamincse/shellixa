# Contributing to Shellixa

We love your input! We want to make contributing to Shellixa as easy and transparent as possible.

## 🍴 Fork & Pull Request
1.  Fork the repository.
2.  Create a new branch for your feature or bugfix (`git checkout -b feature/cool-new-thing`).
3.  Commit your changes following our **Coding Guidelines**.
4.  Push to your fork and submit a Pull Request.

## 📜 Coding Guidelines
-   **Language**: Typescript (Frontend/Backend) or Rust (Core).
-   **Styling**: Use ESLint and Prettier for consistent formatting.
-   **Testing**: Ensure new features are accompanied by unit tests.
-   **Documentation**: Update the relevant markdown files in `/docs` if you change functionality.

## 🐛 Issue Reporting
- Use the **GitHub Issues** tracker to report bugs.
- Provide a clear description, steps to reproduce, and your OS version.
- Check if the issue has already been reported before opening a new one.

## 💬 Community & Communication
- Join our Discord/Matrix channel (Link in README).
- Be respectful and follow our Code of Conduct.
